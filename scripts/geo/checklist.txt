GeoJSON uses [Longitude, Latitude] [cite: 0.6.15], 
while many legacy geographic databases, shapes, and formats output [Latitude, Longitude]


If the source file contains a MultiPolygon (disjointed islands, or a polygon split by 
the Antimeridian) [cite: 0.6.2], the bounding box (.bounds) calculated will cover 
the entire space between the elements

For two small islands on opposite ends of a country, a single bounding box will force the 
loop to iterate through thousands of empty tiles sitting in the ocean between them. 
The engine must check the bounding box of each sub-polygon independently rather than 
using the global MultiPolygon bounds


checking intersections can produce microscopic fractions (e.g., 0.000000001 area overlap). 
Your loop must explicitly define a microscopic tolerance threshold (e.g., ignoring 
intersections where fraction < 0.0001) to prevent returning empty "ghost" tiles


Upstream datasets frequently contain invalid shapes, such as "bow-tie" self-intersections 
(where a polygon crosses its own edge). Do not run calculations on arbitrary shapes.
